# Dist layout reference

The dev build for a given MuJoCo version/ref lives under `dist/<ver>/`. A validated build promoted into the source checkout keeps the same internal shape under `deliverables/<ver>/`.

## Directory layout (typical)

```text
dist/<ver>/
  mujoco.js
  mujoco.wasm
  version.json             # generated release metadata
  provenance.json          # additive build/runtime provenance
  LICENSE                  # carried into release packages
  NOTICE* / notices/       # when present in the source checkout
  pthreads/                # optional (when built with --pthreads)
    mujoco.js
    mujoco.wasm
    mjwasm_forge.js        # compatibility worker alias, when present
    mjwasm_forge.wasm
    version.json
    provenance.json
    *.worker.*             # Emscripten thread worker stubs (name varies)
  abi/
    exports.lst
    exports_check.json
    exports_check.pthreads.json  # optional (pthreads export check output)
    exports_report_funcs.md
    nm_symbols.json
    nm_coverage.single.json       # flavor-specific coverage, when generated
    nm_coverage.pthreads.json     # flavor-specific coverage, when generated
    js_signature_capabilities.json # JS/raw-call classification, when generated
    wrapper_exports_funcs.json
    functions_introspect_like.json
    structs_introspect_like.json
    enums_introspect_like.json
    mujoco_ast.json
```

Replace the leading `dist/` with `deliverables/` when referring to a committed baseline.

## Key ABI files

| File | Role |
| --- | --- |
| `exports.lst` | Export contract used by the Emscripten link step. |
| `nm_symbols.json` | Inventory of implemented symbols (for export/coverage checks). |
| `wrapper_exports_funcs.json` | Wrapper exports generated by `abi_exports/*`. |
| `exports_report_funcs.md` | Human-readable export status report. |
| `provenance.json` | Additive release manifest with runtime SHA-256 values and optional verified build-receipt fields. |
| `nm_coverage.<flavor>.json` | Flavor-specific symbol coverage tied to the corresponding runtime artifact. |
| `js_signature_capabilities.json` | Type-driven JS capability/raw-call classification and adapter notes. |
| `*_introspect_like.json` | Header-derived declarations for diff/audit. |
| `mujoco_ast.json` | Clang AST dump (large; mostly for debugging and auditing). |

The committed `deliverables/<ver>/` tree is the source for release packaging; `dist/<ver>/` is dev-only staging.
The runtime zip excludes `abi/`, while the audit zip contains `abi/` and the same legal files. A pthread worker alias is
copied as-is and is never synthesized by the packager.
